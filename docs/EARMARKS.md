## When they are built

As read from Mikey's words after pass KC: the kindergarten electives finish the full standard first (finished in pass KJ), then these are built (E1 in pass KK, E2 in pass KL, E3 in passes KM and KN, E4 in passes KO and KP, E5 in passes KQ and KR, E6 in pass KS; every kindergarten earmark is built), so kindergarten is complete, standards and all, before grade 1 begins. Mikey can move the line; if he does, say so here. Each is built to the full standard (docs/FABLE-REVIEW.md), with its codes read in full in the published text, and marked done here with its pass.

Before building one, check whether a kindergarten course already teaches part of it (the electives still under review may, for instance Me and my mind teaches the five senses) and narrow the earmark rather than teach it twice.

## How to add one

Add a row with the next number, the published text the code was read in, what is missing in the standard's own words, the pass and Waiting, and say it in that pass's DECISIONS entry. When one is built, change its status to Done with the pass.
