# Art requests

The ledger of every picture the app is waiting for. Mikey makes each one in Leonardo.ai (Nano Banana 2), exports PNG or JPG, and uploads it with its serial; Claude resizes it to about 1200 px, converts it to WebP, and drops it at the path the serial maps to. A missing picture shows a placeholder with its serial in the app until then.

Serials: **S** story scene, **C** core character reference sheet, **I** item pictures for matching modules, **G** games and coloring pages, **L** logo. Numbers never change once given.

Where a file goes: `S7` becomes `art/stories/S7.webp`. Character sheets (`C`) are references for Leonardo only and are not shipped in the app.

Prompt rule (from Mikey's template): `[Core Subject Concept], [Playful Modifier]. Style: Clean 3D vector illustration, vibrant and engaging color palette, minimalist background, balanced lighting. Professional educational graphic style, clear focal point, uncluttered layout, [Visual Anchor].` Every prompt below follows it. Negative prompt always forbids text. Stick to one Leonardo model pipeline for the whole set.

Where a story stars a core character, the prompt names the character sheet to use as the reference (Leonardo's character reference feature), so the same person looks the same in every scene.
